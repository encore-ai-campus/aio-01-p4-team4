## 평가 방법

- `positive`: 기대 문서·절이 검색 상위 3개 안에 있으면 hit@3 = 1. 직원 문서는 staff 역할에서만 검사.
- `deny_staff`: all 역할에서 직원 문서가 **한 건도** 검색되거나 답변에 노출되면 안 됨. 점수 대신 누출 0건 여부를 기록.
- `no_ground`: 정답 문서가 없으므로 검색 점수가 높더라도 사실처럼 답하지 않아야 함. 별도의 무근거 답변률로 기록.
- `no_external_leak`: YES24·NOL 공식 주소, AI 생성·테스트 사유가 고객 답변 근거로 노출되지 않음을 확인.
- 실행별로 `top1_doc`, `top1_section`, `top1_score`, `hit_at_3`, `actual_behavior`, `execution_id`를 CSV에 채움.
- 권한은 사용자 질문 내용이 아닌 **인증·테스트 환경에서 지정한 역할**로 설정.

## 주의

- 동일한 정제 지식 문서 스냅샷을 색인한 다음 측정해야 함.

- 정답이 없는 질문은 hit@3의 분모에 넣지 않음.
